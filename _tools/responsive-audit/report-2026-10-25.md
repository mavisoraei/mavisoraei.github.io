## What was measured

For every page at every width the audit injects a probe after the page has settled (intro skipped, lazy content scrolled through, scroll-driven reveal animations frozen at their final state, `prefers-reduced-motion: reduce` emulated so screenshots are deterministic):

1. `document.documentElement.scrollWidth > innerWidth`, plus every visible element whose right (or left) edge leaves the viewport, ranked by how far it sticks out. Elements inside an `overflow-x: auto/scroll` ancestor or a carousel/slider/marquee class are ignored. Elements clipped by a **local** `overflow: hidden/clip` ancestor are kept but marked `clipped` and ranked after unclipped ones.
2. Links, buttons, inputs, selects, textareas, summaries and ARIA buttons under 44×44 CSS px, smallest first. Inline links inside running text are marked `inline` and ranked last (WCAG 2.5.8 inline exception).
3. Body copy under 14px computed: paragraphs, list items, table cells, captions, quotes and lead/copy blocks with their own text. Header, footer, nav, breadcrumbs, uppercase eyebrows and UI chips are excluded.
4. `position: fixed` or `sticky` elements taller than 25% of the 900px viewport.
5. Images wider than their container content box, missing `width`/`height` attributes, or broken.
6. Long unbroken tokens (URLs, hashes) and tables whose content actually overflows; `contained` means a scroll wrapper mitigates it.
7. The viewport meta tag (missing, `maximum-scale`, `user-scalable=no`).
8. The computed `h1` font-size and line-height at every width.

> Note on `overflow`: `body { overflow-x: clip }` hides off-viewport children from `scrollWidth` on this site. The **Doc overflow** column therefore reports real document scroll; the **Off-viewport** column reports elements that leave the viewport even when the body clip hides them.

## Method notes and limits

- Touch emulation is on below 1000px (`Emulation.setTouchEmulationEnabled`), with a device metrics override at each width and height 900.
- The page-load intro is skipped with a real Escape key, exactly like a visitor; if the intro script never arrived the harness removes the scroll lock itself.
- Full-page screenshots are capped at 10000px tall; taller pages are marked as clipped in the raw JSON (`shot.clipped`).
- `body { overflow-x: clip }` means elements can leave the viewport without raising `scrollWidth`. Both signals are reported separately, and `clipped` marks elements hidden by a local clipping ancestor.
- Fixed/sticky coverage is measured at scroll position 0 against the 900px viewport.
- Font sizes are computed values at the audit viewport, not authored values; fluid `clamp()`/`vw` sizing is reflected as measured.
- This harness only reads the rendered page. It does not modify, build or deploy anything.
